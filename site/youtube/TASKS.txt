PART D — PREPARE THE COMPUTER DEMO (only if using Option 2)
-----------------------------------------------------------
[ ] D1. Open a terminal.

[ ] D2. Type this and press Enter:
        cd /home/iwlnx/src/newproj

[ ] D3. Make sure the project builds (first time may take a few minutes):
        cargo build -p npc --bin lhsc

[ ] D4. Practice this command (you will run it on camera):
        cargo run -p npc --bin lhsc -- test examples

[ ] D5. Practice this second command:
        cargo run -p npc --bin lhsc -- run --jit examples/17_use_math.lhs

[ ] D5b. Practice STANDALONE builds (two-language demos — do these):

        cargo build -p npc --bin lhsc

        # BEST for the two-language pitch (numeric → binary):
        ./target/debug/lhsc build apps/mandelbrot.lhs -o mandelbrot
        ./mandelbrot

        ./target/debug/lhsc build apps/busy_bench.lhs -o busy_bench
        ./busy_bench

        # Optional fuller app (shipping story, not classic numeric rewrite):
        ./target/debug/lhsc build apps/day_planner.lhs -o day_planner
        ./day_planner
        At the > prompt type:  month
        Then type:             9/21
        Then type:             quit

[ ] D6. Open the landing page in your browser BEFORE recording:
        https://larrysikes.github.io/lhs/
        Keep that tab ready for the end of the video.


PART E — RECORD THE VIDEO
-------------------------
Rough order (follow the script):

[ ] E1. Start recording.

[ ] E2. Look at the camera. Say the HOOK
        (two languages / rewrite problem) — about 20–30 seconds.

[ ] E3. Say WHAT LHS is
        (one language, .lhs files, lhsc compiler) — about 25 seconds.

[ ] E4. Say the COMPARE + HONEST part (important — do not skip):
        “Julia and Nim already attack this at scale.
         Rust is a great second language.
         LHS is a small open MVP — write, build, binary —
         not a claim we beat those ecosystems.”
        About 30–40 seconds. Exact words are in ANNOUNCEMENT.txt
        under [COMPARE] and [HONEST].

[ ] E5. If computer demo:
        Switch to terminal. Run the commands from D4 and D5.
        Let the output stay on screen a few seconds.

[ ] E5b. Mandelbrot (say out loud):
        “People often rewrite numeric code in C. Here we keep LHS
         and ship a standalone binary.”
        Build and run mandelbrot from D5b. Let the picture draw.

[ ] E5c. Busy bench:
        Build and run busy_bench. Point at serial/parallel timings.

[ ] E5d. Optional — day planner:
        Build and run day_planner; type month, 9/21, quit.

[ ] E6. End on the landing page in the browser.
        Say the URL slowly once:
        “larrysikes dot github dot io slash lhs”

[ ] E7. Ask viewers to try mandelbrot or the bench, or star the repo.
        Optional closing line: “Tell me how you’d compare us to Julia or Nim.”


[ ] E8. Stop recording. Save the file somewhere easy, for example:
        /home/iwlnx/Videos/lhs-announcement.mp4
