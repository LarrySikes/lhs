LHS STATUS — v0.4 (2026-09-21)
================================

WHAT THIS IS
  LHS = general-purpose language (ease + native code + safety story).
  CLI = lhsc. Sources = *.lhs. Repo = ~/src/newproj.

  Separate from IWAI/UCC (~/src/iwai_project). See HOW_WE_GOT_HERE.txt.

DONE (north-star / v0.4)

  - Interpreter: full language + parallel task/await (OS threads)

  - CI workflow, dual license, docs

  - Not production-hardened (see manifesto non-goals)
